grille 6x8, tu choisis juste la colonne, le bouton tombe comme au puissance 4
3 familles de boutons : bone, wood, brass. valeurs 1 à 5

tu ne scores QUE si tu as la partition correspondante équipée (4 slots max)
partitions = formes + règles (ligne famille, carré chiffre, suite, losange…)
figure sans partition = les boutons restent et cloggent

lignes : v x1, h x1.5, d x2 — stacking vertical pénalisé par design
cascades x2 par niveau

tu as un stream de jetons + 1 slot de hold, pas de défausse, un seul passage dans le deck
30 boutons + 4 rocks (scaffold, explosent en fin de manche) + spéciaux achetés

spéciaux = outils one-shot (bombe, fantôme, marée), consommés à la manche suivante
t'en achètes 2-3 pour une manche chaude

badges = passifs permanents (5 slots max)
exemples : +3 mouches par cascade, cellule x3 random chaque manche, colonnes centrales x1.5 / bords x0.5, patterns famille x2
chaque badge a son script, synergies émergentes

cellules modifiées : half x0.5, boost x1.5, double x2, triple x3
posées par badges / layouts de zones / spéciaux / entity

deck vide → dernier souffle : rocks explosent, cascade surprise, verdict
score cible pas atteint = game over, fin de run

entre chaque manche : shop tenu par grenouilles orchestre
tu payes en mouches
offre mixte : items visibles unitaires + packs rng (bocaux boutons / recueils partitions / malles spéciaux / paquets cartes)
reroll croissant

entity = petit skull lâché dans une colonne random tous les 6 tours, survit à tout, brise le stacking

run = 4 zones x 3 manches, monnaie de progression = tickets
fin de run → the shore (meta-progression, unlocks pour les futures runs)
