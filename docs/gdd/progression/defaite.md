# Condition de défaite

**[Deck](../manche/deck.md) vide + [score cible](../manche/score-cible.md) pas atteint = game over, fin de run.**

## Principe

Pas de vies. Pas de seconde chance. Pas de perte progressive de mouches.

C'est **brutal et clair**. Le joueur sait exactement pourquoi il a perdu — son build n'était pas assez fort ou son placement était mauvais. Pas d'ambiguïté, pas de "la chance n'était pas avec moi".

## Après la défaite

- Écran de fin de run (score final + cible)
- Bouton "Nouvelle run"
- Retour au [Shore](../shore/principe.md) pour la meta-progression

## Pourquoi pas de sauvegarde de manche

On a écarté toutes les formes de "seconde chance" (rewind, revive, save-state) parce qu'elles diluent le poids des choix pendant la manche. Le fait de savoir qu'on peut perdre à chaque drop est ce qui rend les décisions importantes.
