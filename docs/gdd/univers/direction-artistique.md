# Direction artistique

**Hand-drawn assumé.** Silhouettes fortes, aplats, palette limitée. Charme > polish. Modèle Sol Cesto, pas Hades.

## Traitement lumière

Fond sombre, éléments qui émettent leur propre lumière. Écho de la migraine — le monde familier mais de travers. La grille comme une petite lumière dans le noir.

## UI

L'UI est le monde, pas une interface posée dessus. Références : Sol Cesto (le shop est tenu par des personnages, pas un écran) + Hades 2 (le marchand est dans la pièce, le décor raconte le vendeur).

## Pipeline

Illustrations statiques + juice en code. Thomas dessine lui-même en Photoshop (expérience : Licky's Escape).
