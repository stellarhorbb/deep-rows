# The Shore — unlocks

Ce que le joueur peut débloquer au Shore pour enrichir ses futures runs.

## Nouvelles [grilles](../grille/format.md)

Nouvelles formes de terrain avec dimensions différentes, layouts spéciaux ([modifiers](../grille/modifiers-cellules.md) pré-placés), mécaniques uniques.

## Nouveaux packs de [boutons](../jetons/boutons.md)

Nouvelles fondations de deck avec compositions de familles/valeurs différentes.

## Nouveaux [jetons spéciaux](../jetons/specials.md)

Nouveaux outils qui apparaissent dans le pool du shop.

## Nouvelles [Partitions](../partitions/principe.md)

Nouvelles manières de scorer. Les Partitions exotiques (Fibonacci, Parfait, Rainbow...) sont débloquées ici.

## Nouvelles [Badges](../badges/principe.md)

Nouveaux passifs qui enrichissent le pool du shop. Les Cartes [Epic](../badges/rarete.md) sont principalement débloquées ici.

## Ressource de meta-progression

À trancher. Pistes :

- **Tickets** accumulés en fin de run (proportionnel à la progression atteinte)
- **Découvertes** : certains unlocks se font par des achievements en jeu ("former un pattern de 6+ pour la première fois", "finir une manche avec exactement le score cible", "compléter une run sans acheter de spécial")
- **Combinaison** des deux
