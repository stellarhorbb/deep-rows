# The Shore — principe

Le hub de meta-progression entre les runs.

*"The Shore" est un **nom placeholder** — le lieu de retour définitif reste à trouver, cohérent avec l'univers halluciné (voir `brainstorm-univers.md`).*

## Principe

The Shore n'est **pas** un système de craft pendant le run. C'est le lieu où le joueur débloque du nouveau contenu pour ses futures runs.

Modèle : la Maison de Hades. Entre les runs, on dépense des ressources pour enrichir le pool de ce qui peut apparaître dans les prochaines parties.

## Rôle dans la boucle

- Point de retour après chaque run (game over ou victoire — peu importe)
- Lieu narratif qui évolue subtilement run après run
- Moteur de rejouabilité : "j'ai débloqué X, je veux tester ça"
